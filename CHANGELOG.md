# Changelog

## 0.10.0
- Вкладка «Модераторы» (назначение по email, автоматическая роль при регистрации, отзыв), прямое удаление профилей администратором.
- Изоляция аккаунтов: тема и состояние плеера привязаны к пользователю, сброс при выходе.
- Тема Industrial Brutal заменена на Graphite Glass.
- Плеер: закрытие, изменение высоты, скрытие обложки в компактном режиме.
- Жанр/исполнитель/настроение: выпадающий список с автодополнением и вводом нового значения.
- Единый список обращений в «Уведомлениях» для модераторов и админов.
- Заглушка аватара — медуза сайта; исправлено скачивание треков; уникальные ники `@name` вместо числовых ID (миграция 0004).

## 0.9.0 — соцсеть
- Роли (гость / пользователь / модератор / администратор), серверные проверки доступа, закрытые профили, взаимные блокировки.
- Друзья, подписки, лента (друзья + рекомендации по вкусу), посты с текстом, до 8 изображений и треками, глобальный поиск, уведомления.
- Совместные плейлисты (соавтор / слушатель), чаты с отправкой контента и медузой-питомцем, выделение чатов и уведомлений от модерации цветом темы.
- Модерация: очередь жалоб, карточка, шаблоны ответов, предупреждения, профили со статусами; запрос удаления профиля с подтверждением администратором.
- Администрирование: статистика (DAU/WAU и др.), пользователи и роли, восстановление, журналы действий, настройки платформы.
- Миграция `0003`; описание страниц — `PAGES.md`.

## 0.8.0
- Дизайн: 8 тем из референсов (Plasma, Cognac Leather, Neon Red, Forest Enchanted, Glass Green, Y2K Butterfly, Sepia Vintage, Industrial Brutal), токены в `tokens.css`; раскладка возвращена к исходной.
- Маскот: точная трассировка референса, состояния idle / active / thinking / error / icon, новая фавиконка; аватар профиля не менялся.
- Плеер: собственные кнопки и ползунок; после обновления страницы возвращается последний трек и позиция.
- Профиль: подтверждение при смене публичности. Фильтры: свои жанры/настроения/исполнители сохраняются на сервере (миграция 0002). Редактор плейлиста: «Выбрать все» уменьшена и перенесена под кнопку.

## 0.7.0
- Редизайн в стиле Liquid Glass: токены (`tokens.css`), компоненты (`glass.css`), 5 палитр, адаптивная раскладка (сайдбар на десктопе, плавающая навигация на мобильных).
- Маскот-медуза: состояния idle / happy / thinking / error / icon, фавиконка, витрина компонентов `/#/ui`.
- Старый `styles.css` и 30+ тем удалены.

## 0.6.0
- Бэкенд: добавлен Alembic (миграция 0001), таблицы создаются при старте; исправлен падающий `get_playlist`.
- Плейлисты: CRUD, порядок треков (`PUT /playlists/{id}/items/order`), обложка, публичная ссылка `#/playlist/{id}` без авторизации, удаление.
- Загрузка треков: проверка расширения/сигнатуры/размера, теги (mutagen) и имя файла → название/исполнитель, подсказка «Неизвестный исполнитель», `GET /tracks/{id}`.
- Профиль: `GET /users/{id}` с серверной проверкой публичности.
- HTTP-коды приведены к списку из ТЗ (200, 201, 204, 400, 401, 403, 404, 422).
- Фронтенд: удаление треков, раздел «Заметки», автопереход к следующему треку, исправлена модалка плейлиста.
- Версии зависимостей — строго по requirements.txt; package.json согласован с package-lock.json.
